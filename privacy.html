Privacy policy

Last updated: 4 November 2026.

movie-ai-analytics is a personal tool used only by the owner of the connected YouTube channels.

What data it accesses

With the owner's permission it reads, in read-only mode, the list of the owner's videos and their statistics (views, likes, comments, watch time, traffic sources and similar channel analytics) through the YouTube Data API and the YouTube Analytics API.

How the data is used and stored

The data is stored only on the owner's own computer and is used only to analyse the performance of the owner's videos. It is not sold, shared with or transferred to third parties, and it is not used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service.

Contact

Questions can be raised through the owner's GitHub profile: github.com/timurrma.
